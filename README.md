# SimpleLang Interpreter (Java + ANTLR)

> **Work in progress.** This is university coursework (Compilers and Computer Architecture, University of Sussex) that I'm still working on, so expect changes.

An interpreter for **SimpleLang**, a small typed language, written in Java. ANTLR generates the lexer and parser from my grammar, and the interpreter walks the resulting parse tree to type-check and run programs.

## What it does so far

- **Grammar** (`task1/src/SimpleLang.g4`): functions with typed parameters, local variables, `int` / `bool` / `unit` types, `if … then … else`, `while … do`, `repeat … until`, `print`, and arithmetic, comparison and boolean operators.
- **Semantic checks** that reject bad programs before they run: duplicate functions, names that clash with functions or with each other, undeclared variables, wrong argument counts, and a missing `main`.
- **Type checker**: works out the type of every expression and rejects programs that mix types incorrectly.
- **Interpreter** (`task1/src/SimpleLangInterpreter.java`): runs the program using the visitor pattern, with a stack of call frames for function calls and local variables.

## Example

```
int main(int n) {
    int total := 0;
    while (0 < n) do {
        total := (total + n);
        n := (n - 1)
    };
    print total;
    total
}
```

## Running it

```bash
./gradlew build
java -cp "task1/build/classes/java/main:antlr-4.13.1-complete.jar" Task1 5 < program.simp
```

Program arguments are passed to `main`. The `task1tests/` folder holds 24 test programs with their expected output, including programs that must be rejected. All 24 currently pass.

## Who wrote what

- **My code:** the grammar (`SimpleLang.g4`) and the interpreter (`SimpleLangInterpreter.java`).
- **Generated by ANTLR:** `SimpleLangLexer.java`, `SimpleLangParser.java`, `SimpleLangVisitor.java`, `SimpleLangBaseVisitor.java` and the `.interp` / `.tokens` files.
- **Provided with the coursework:** `Task1.java`, `Task1Tester.java` and the build setup.
